How to write a strong prompt

A strong prompt names the actor, trigger, main steps, decisions, failure paths, and final outcomes. Instead of writing "make a login flow," describe account lookup, password validation, OTP checks, success states, and retry paths.

Example prompt

"Create a customer refund approval flow. Start with a refund request. Check if the order is within the return window. If not, reject the request and notify the customer. If yes, send the item to quality review. If approved, process the refund. If rejected, send an explanation and close the request."

FAQ

Can I edit the generated flowchart?

Yes. You can add nodes, connect links, label arrows, change shapes, switch layout direction, and export Mermaid, SVG, or PNG.

Is this only for Mermaid users?

No. Mermaid export is available, but the app also renders visual diagrams and supports image export.
