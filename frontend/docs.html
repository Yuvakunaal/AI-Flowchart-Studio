How to use AI Flowchart Studio

AI Flowchart Studio helps you generate flowcharts from text, refine them manually, and export diagrams for documentation, planning, and team communication.

Set up your Gemini API key

  1. Open the app homepage.
  2. Expand Gemini API Settings.
  3. Paste your Gemini API key.
  4. Click Save Key. The key is stored locally in your browser.

Generate a flowchart

  1. Describe the process in the prompt box.
  2. Include the start point, actions, decisions, and outcomes.
  3. Click Generate Flowchart.
  4. Review the rendered diagram and adjust it as needed.

Edit manually

Use the Manual Builder to add nodes, connect links, label branches, choose shapes, and refine AI-generated diagrams without writing code.

Export options

  • Copy Mermaid code for README files and documentation.
  • Download SVG for sharp, scalable graphics.
  • Download PNG for slides, chat messages, and quick sharing.

Prompt example

"Create a login flow. Start when a user enters email and password. Check whether the account exists. If not, route to signup. If it exists, verify the password. If verification fails, show retry. If it succeeds, require OTP for new devices and then show the dashboard."
