Overview

AI Flowchart Studio is a browser-based diagram tool that converts plain-language descriptions into structured visual diagrams using Google's Gemini AI. You can also build diagrams from scratch using the Manual Builder — no AI key required.

All diagrams are rendered using Mermaid.js — an open standard for text-based diagrams — giving you clean, scalable output you can export or drop directly into GitHub, Notion, or any Mermaid-compatible tool.

Quick Start

Create your first AI-generated flowchart in under two minutes.

1

Get a free Gemini API key

Visit Google AI Studio at aistudio.google.com and create an API key. The free tier supports hundreds of generations per day — no credit card needed.

2

Paste your key into the app

Expand Gemini API Settings in the left panel, paste your key, and click Save Key. Your key is stored only in your browser — you'll do this once per device.

3

Describe your flow and generate

Type your process description in the AI Generate tab and click Generate Flowchart. Your diagram renders on the canvas in real time.

💡

No API key? Use Manual Mode

Switch to the Manual Builder tab to construct diagrams node-by-node without any API key.

API Key Setup

AI Flowchart Studio uses a BYOK (Bring Your Own Key) model. You supply your Gemini API key and the app uses it to call Google's Gemini API directly from your browser.

Getting your key

1

Open Google AI Studio

Go to aistudio.google.com and sign in with your Google account.

2

Create an API key

Click Get API Key → Create API key. Select or create a Google Cloud project if prompted.

3

Copy and paste into the app

Copy the key (starts with AIza…), expand Gemini API Settings in the app, paste it, and click Save Key.

🔐

How your key is stored

Your API key is saved in localStorage in your browser. It is only transmitted to Google's Gemini API when you click Generate — it never passes through AI Flowchart Studio's servers.

⚠️

Keep your key safe

Don't share your API key or paste it into unknown sites. If you think your key is compromised, revoke it in Google AI Studio and generate a new one.

AI Generation

The AI tab sends your prompt to Google Gemini, which returns valid Mermaid flowchart syntax. That code is rendered live on the canvas as an interactive SVG diagram.

How it works

1

You write a prompt

Describe your process in the text area. Include start points, decision branches, and end states for best results.

2

Gemini converts it to Mermaid code

Your prompt is sent to Gemini with a system instruction that constrains the output to valid flowchart TD Mermaid syntax only — no prose, no explanation.

3

The diagram renders on the canvas

Mermaid.js parses the returned code and renders it as a scalable SVG. You can pan, zoom, click nodes to edit, and export immediately.

After generation

  • Click any node on the canvas to open the node editor — rename it or change its shape on the spot.
  • The Mermaid Output field shows the raw code — edit it directly and hit re-render for precise tweaks.
  • Generate again with a refined prompt to replace the diagram entirely, or combine prompt + manual edits.
💡

Generation failing?

Check that your API key is saved and valid. If the status list shows a network error, your free-tier quota may be exhausted for the day — check Google AI Studio for usage limits.

Prompt Writing Guide

The quality of your diagram depends on the quality of your prompt. Gemini infers structure well — but the more explicit you are, the more accurate the result.

What to include in a prompt

  • Start node — Where does the process begin? (e.g. "Start when the user reaches the checkout page")
  • Actions — What happens at each step? Use verbs: validate, check, send, display, redirect, notify.
  • Decision points — Where does the flow branch? Explicitly name both paths: the Yes/success path and the No/failure path.
  • End states — What are the possible termination points? Name each one. There can be more than one.

Real prompt examples

User authentication flow
Create a login flow. User enters email and password. Check if account exists — if not, show "account not found" and offer signup. If it exists, verify password — if wrong, increment failure counter; after 3 failures lock the account. If password correct and device is new, send OTP — if OTP fails, reject. If OTP passes or device is recognized, redirect to dashboard.
E-commerce order processing
Show an e-commerce order process. Start when customer clicks "Place Order". Validate payment — if invalid, show error and retry. If valid, charge card — if declined, show failure. If charged, check inventory — if out of stock, refund and notify customer. If in stock, create order record, send confirmation email, trigger warehouse dispatch, set tracking to "Processing". End.
CI/CD deployment pipeline
Document a CI/CD pipeline triggered on git push. Run unit tests — if failing, notify developer and stop. If passing, run integration tests — if failing, alert team and stop. If passing, build Docker image and push to registry. Deploy to staging, run smoke tests — if failing, roll back and alert. If passing, wait for manual approval — if rejected, stop. If approved, deploy to production, run health check, post Slack notification. End.

Tips for better results

  • Use natural connective words: if, then, otherwise, when, after, on success, on failure
  • Name each branch outcome explicitly: "if valid → …" and "if invalid → …"
  • One action per node — don't bundle multiple actions into one step
  • State every end state explicitly so Gemini knows where branches terminate
  • For very complex flows, break into sub-processes and generate them separately
✨

Iterate, don't perfect

Generate a first draft, see what comes out, then refine the prompt with more specifics. Two or three iterations usually produces a polished result faster than writing one long prompt upfront.

Manual Builder

The Manual Builder tab lets you construct diagrams node-by-node without AI. It's useful for precise, predictable diagrams, for adding nodes to an AI-generated base, or when you don't have an API key.

Node types

▭
Rectangle
Standard process step. Use for actions, tasks, or states. The default and most common node type.
◇
Diamond
Decision point. Use for Yes/No questions or branching conditions that split the flow.
○
Circle
Terminal node. Use for the explicit start or end point of a flow.
╭▭╮
Rounded Rectangle
Soft-edged process step. Often used for start/end states in flowchart conventions.

Adding nodes

1

Switch to Manual Builder tab

Click Manual Builder in the left panel tab row.

2

Enter a node label

Type the text that will appear inside the shape in the Node Label field.

3

Choose a shape and click Add Node

Select Rectangle, Diamond, Circle, or Rounded from the shape dropdown, then click Add Node. The node appears in the list and renders on canvas.

Connecting nodes

Once you have at least two nodes, use the Connect Nodes section:

  • Select the From node (origin) from the first dropdown
  • Select the To node (destination) from the second dropdown
  • Optionally add an Edge Label — e.g. "Yes", "No", "On success", "Error"
  • Click Add Connection to draw the arrow between them

Editing nodes after rendering

Click any node on the canvas to open a floating editor. Change the label or shape and the diagram re-renders immediately. You can also delete individual nodes from the node list in the left panel.

ℹ️

Mixing AI and manual

Generate a base diagram with AI, then switch to Manual Builder to add or refine individual nodes. The Mermaid code in the output field reflects all changes in real time.

Canvas Controls

The canvas is a scrollable, zoomable area that holds your rendered diagram. Navigate it with your mouse, trackpad, or the on-screen controls.

Navigation

  • Pan — Click and drag the canvas background to move around the diagram.
  • Zoom — Use the + / − buttons in the bottom-right corner, or the zoom percentage dropdown in the toolbar.
  • Fit to screen — Click the Fit button in the toolbar to reset zoom so the full diagram is visible.
  • Reset zoom — Click the zoom percentage button to snap back to 100%.

Interacting with nodes

  • Click a node to open the floating Node Editor — edit the label or change the shape.
  • Hover a node to see a subtle indigo glow highlight.
  • The active (selected) node is outlined with an indigo border.
  • Press Esc or click outside to close the node editor.

Toolbar quick reference

  • Layout — Switch flow direction: top-to-bottom (TD), left-to-right (LR), bottom-to-top (BT), right-to-left (RL).
  • Undo / Redo — Step backward or forward through your edit history.
  • Clear — Wipe the canvas and start a fresh diagram.
  • Export — Open the export menu for Mermaid code, SVG, or PNG.
  • Docs — Opens this documentation page in a new tab.

Embedding Mermaid in GitHub

GitHub natively renders Mermaid in Markdown files. Wrap your exported code in a fenced code block tagged mermaid:

Markdown 
```mermaid
flowchart TD
    A([Start]) --> B[Enter Credentials]
    B --> C{Account exists?}
    C -->|Yes| D[Verify Password]
    C -->|No| E[Show Signup]
    D -->|Correct| F([Dashboard])
    D -->|Wrong| G[Show Error]
```

FAQ

Is my API key sent to your servers?

No. Your key is saved only in your browser's localStorage. When you click Generate, it is sent directly from your browser to Google's Gemini API. AI Flowchart Studio's backend never receives or stores your key.

Do I need to pay for the Gemini API?

The Gemini API has a generous free tier supporting hundreds of generations per day — enough for personal and team use. Heavier usage may require a paid Google Cloud plan. Check Google AI Studio for current rate limits and pricing.

What diagram types can I create?

AI Flowchart Studio outputs Mermaid flowchart diagrams — covering flowcharts, process maps, decision trees, system architecture diagrams, CI/CD pipelines, user journeys, and any flow with nodes and directed edges. Sequence diagrams, Gantt charts, and ER diagrams are outside the current scope.

How are my diagrams saved?

Diagrams are saved as named projects in your browser's localStorage. They persist between sessions on the same browser and device but are not synced to any cloud. Clearing your browser data will delete saved projects — use the Mermaid code export as a portable backup.

The generated diagram looks wrong — what do I do?

Try refining your prompt with more explicit branching language. If the structure is mostly correct, click individual nodes to edit them directly. For large mis-renders, inspect the Mermaid output field for syntax errors, fix them inline, and re-render manually.

Can I use the Manual Builder offline?

The Manual Builder works without an internet connection once the page is loaded — it makes no API calls. AI generation requires connectivity to reach the Gemini API. The Mermaid rendering library is loaded from a CDN, so the initial page load needs connectivity too.

Can I embed the exported SVG on my website?

Yes. The exported SVG is a standard vector file. Embed it with an <img> tag, inline it directly in HTML, or import it into Figma and other design tools. Diagrams you create are yours — no attribution required.
